**Machine learning engineer — reinforcement learning, computer vision, and LLM evaluation.**

I build systems that decide: agents that act on noisy, incomplete observations, update

## 🔬 What I work on

- 🎯 **Sequential decision-making under uncertainty** — deep reinforcement learning and
  Decision Transformers over belief states, where the environment is only visible through
  noisy sensors
- 🖼️ **Computer vision** — semantic segmentation and image translation with U-Net
  (98% IoU on satellite imagery), image classification with ResNet and VGG, and
  generative models (score-based diffusion)
- 🎲 **Probabilistic state estimation** — particle filters, sequential Bayesian updating,
  sensor fusion
- 🤖 **Agentic AI and LLMs** — fine-tuning with LoRA, retrieval, and automated
  LLM-as-a-judge evaluation
- 🛡️ **Trustworthy and robust models** — adversarial training, Bayesian neural networks
- 🚀 **Research into production** — a system I designed runs inside a commercial platform
  that engineers use in live operations
